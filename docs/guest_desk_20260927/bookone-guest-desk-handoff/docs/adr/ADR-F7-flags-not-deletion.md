# ADR-F7 — Existing modules are flagged, not removed
Status: Accepted · Date: 2026-09-27

## Decision
The Docs 00–09 build is preserved in full. Out-of-scope modules default OFF per ADR-F2. Restaurant booking remains ON
for restaurant tenants. Fiscal core (D11) stays deferred behind its original six conditions; the statutory
guest-registration core (Alloggiati/ISTAT/tassa) is un-deferred to Phase 1 — these are different things.
