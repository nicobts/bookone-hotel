# ADR-F8 — Provincial motion first; national approach after three regions
Status: Accepted · Date: 2026-09-27

## Decision
Expansion unit = one region: one ISTAT ComplianceAdapter + one comune rule table + one provincial association
convenzione. First region: Friuli Venezia Giulia (WebTur, Comune di Trieste). Second: Veneto (ROSS1000).
A national association approach is made only after three regions are live with signed conventions and 30-day pilot
metrics. Technical implication: the region adapter registry is a first-class concept from WP1.1.
